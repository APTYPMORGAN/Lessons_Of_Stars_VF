## Шаг 2. Подключить НАСТОЯЩЕЕ расписание (без копирования вручную)

Сейчас в `vk_bot/data/schedule.json` лежит тестовая заглушка «ТЕСТ-001». Её надо убрать, а бот должен читать ваш реальный файл из TG-проекта.

Выполните в Git Bash (выключив Telegram-бота на время команды, чтобы SQLite/файл не был занят — JSON это не мешает, но на всякий случай):

```bash
cd /d/Downloads/VFStudentBot
rm vk_bot/data/schedule.json          # удалить заглушку
rmdir vk_bot/data                      # удалить папку vk_bot/data целиком
ln -s ../data vk_bot/data              # симлинк: vk_bot/data -> реальный data/
```

Проверка, что всё прочиталось (в той же папке проекта, в venv):
```bash
python -c "import json; d=json.load(open('vk_bot/data/schedule.json',encoding='utf-8')); print(len(d), list(d)[:5])"
```
Должно напечатать количество групп и первые имена (например `ИСП-251...`), а не ошибку.

> Если `ln` ругается, альтернатива — скопировать один раз:
> `cp data/schedule.json vk_bot/data/schedule.json`
> Но тогда при обновлении расписания придётся копировать снова. Симлинк лучше.

## Шаг 3. Создать сообщество ВК и включить API

1. ВКонтакте → слева «Сообщества» → «Создать сообщество» → тип «Бизнес» или «Тёмная лошадка», название например «Расписание ВФ ВолГУ».
2. **Управление → Сообщения**:
   - «Сообщения сообщества» → **Включены**;
   - «Типы бесед» → только **Личные сообщения сообщества**;
   - «Доступный адрес» → придумайте (например `vf_schedule`);
   - «Автоматически отвечать на сообщения» → **НЕТ** (иначе автоответ будет мешать боту).
3. Там же вкладка/переключатель **«Боты (Long Poll API)»** → Включить.
4. Раздел «Права доступа» (там же, в настройках сообщений) → включить события:
   - **Личные сообщения** (`message_new`) — обязательно;
   - «Изменение информации о диалоге» — по желанию.
5. Нажмите **«Сгенерировать ключ»** (access token сообщества). Выставьте права: `messages`. Скопируйте ключ — он показывается один раз.

## Шаг 4. Заполнить .env

```bash
cd /d/Downloads/VFStudentBot/vk_bot
cp .env.example .env
notepad .env
```
Заполните:
```text
VK_TOKEN=ключ_из_шага_3        (начинается с 'vk1.a.', БЕЗ кавычек и пробелов)
VK_GROUP_ID=число              (ID сообщества: виден в адресе club12345678 -> 12345678)
VK_ADMIN_ID=ваш_vk_id          (свой ID: https://vk.com/idXXXXXXXX -> XXXXXXXX)
```
Не сохраняйте файл с расширением `.env.txt` (в Notepad: Сохранить как → Тип «Все файлы»).

## Шаг 5. Установить зависимости и запустить

```bash

```

Если пишет про ошибку авторизации — проверьте токен и группу (Шаг 4).

## Шаг 6. Первый тест (со своего аккаунта, НЕ админской проверкой)

Напишите сообществу с другого аккаунта (или попросите одногруппника):
1. `/start` → должны появиться кнопки выбора курса;
2. Пройдите: курс → направление → группа;
3. `/today`, `/tomorrow`, `/week`, `/whatstar`, `/profile`;
4. Проверьте, что старое сообщение бота заменяется новым (не копится);
5. Напишите `/settings` и смените группу.

**Рассылку `/broadcast` пока не тестируем** — сначала убедимся, что расписание показывает верно (как договаривались).
