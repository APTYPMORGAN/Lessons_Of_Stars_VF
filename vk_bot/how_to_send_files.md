# Как передать мне файлы проекта

## Способ 1 (самый простой): вставить текст в чат

1. Откройте файл в VS Code.
2. Выделите всё содержимое: `Ctrl+A`, затем скопируйте: `Ctrl+C`.
3. Вставьте в сообщение мне: `Ctrl+V` и отправьте.

Отдельным сообщением напишите, что это за файл, например:

```text
Это bot.py:
<вставленный код>
```

Файлы, которые нужны мне в первую очередь:

- `bot.py` (можно кусок с GROUPS и функциями расписания, если весь файл очень большой)
- `schedule.py`
- `data/schedule.json`

Если `schedule.json` больше ~500 строк, пришлите два фрагмента:
1) начало файла (~100 строк);
2) любую группу, где есть занятия со звёздочками `"star"` и с полем `"dates"`.

## Способ 2 (через Git — для папок и больших файлов)

Выполните эти команды по очереди в терминале VS Code (Git Bash),
находясь в папке проекта `D:\Downloads\VFStudentBot`:

```bash
cd /d/Downloads/VFStudentBot

git init -q 2>/dev/null

# Создаём .gitignore, если его ещё нет (иначе git add выдаст ошибку
# "pathspec '.gitignore' did not match any files"):
[ -f .gitignore ] || printf '.env\nvenv/\n*.db\n__pycache__/\n' > .gitignore

git add bot.py schedule.py data/schedule.json .gitignore
git commit -qm "files for vk bot review"

git remote add origin https://github.com/ВАШ_ЛОГИН/VFStudentBot.git
git push -u origin master
```

Замените `ВАШ_ЛОГИН` на ваш GitHub-логин. Репозиторий должен быть создан
заранее на github.com (можно приватный, тогда пригласите меня не нужно —
просто пришлите мне ссылку и скриншот/текст файлов, к которым у вас есть доступ).

⚠️ Важно: **не** добавляйте в git файлы с токенами:

```bash
# убедитесь, что эти файлы НЕ попадут в репозиторий
echo ".env" >> .gitignore
echo "bot.db" >> .gitignore
```

(Я уже добавил `*.db`, `.env`, `venv/` в `.gitignore` своей рабочей копии.)

## Чего делать НЕ нужно

- Не присылайте токен Telegram-бота или VK-токен — они мне не нужны.
- Не присылайте `bot.db` и папку `venv/` — это база данных и окружение, код в них нет.
- Не архивируйте проект в zip: я не могу принимать бинарные вложения, только текст.

## Что я сделаю, когда получу файлы

1. Сверю `GROUPS` в `vk_bot/groups.py` с вашим `bot.py`.
2. Сверю формат занятий в `vk_bot/data/schedule.json` (сейчас там тестовая
   заглушка ТЕCТ-001) с вашим настоящим `data/schedule.json` и поправлю
   `schedule_core.py`, если поля называются иначе.
3. Проверю логику недель/дат и времени пар — исправлю расхождения.
4. После этого вы замените тестовый JSON своим и запустите бота.
