# VK-бот с расписанием ВФ ВолГУ

Отдельная VK-версия Telegram-бота (aiogram-бот не трогается).
Транспорт: **Bots Long Poll API** (не требует сервера и HTTPS — бот работает
с вашего компьютера). Библиотека: `vk_api` (совместима с Python 3.13.x,
проверялась на 3.12/3.13; aiogram для VK НЕ используется).

## Структура папки vk_bot/

| Файл | Назначение |
|---|---|
| `vk_bot.py` | Точка входа: long poll, команды, кнопки, рассылка |
| `config.py` | Настройки из `.env` (токен, id группы, id админа) |
| `groups.py` | Справочник курс → направление → группа (**сверить с вашим bot.py!**) |
| `schedule_core.py` | Загрузка `data/schedule.json`, звёздные недели, даты, сокращения |
| `db.py` | SQLite `vk_bot.db` (отдельно от базы TG-бота!) |
| `keyboards.py` | Кнопки VK (inline + reply-меню) |
| `data/schedule.json` | **Сейчас здесь тестовый файл — замените реальным!** |
| `.env.example` | Шаблон секретов (скопируйте в `.env`) |

## Что нужно сделать вам (по шагам)

### Шаг 1. Скопировать реальные данные
Из `D:\Downloads\VFStudentBot`:

```bash
cp "/d/Downloads/VFStudentBot/data/schedule.json" vk_bot/data/schedule.json
```

⚠️ Сейчас в `vk_bot/data/schedule.json` лежит **тестовая заглушка**
(группа «ТЕСТ-001»), потому что у меня нет доступа к вашим файлам.
Её обязательно заменить реальной. Если поля в вашем JSON называются иначе
(например, не `star`/`dates`) — скажите, поправим `schedule_core.py`.

Также сверьте `groups.py` со структурой `GROUPS` из вашего `bot.py`.

### Шаг 2. Создать сообщество ВК и получить токен
1. ВКонтакте → Сообщества → «Сообщество» → создайте группу (например «Расписание ВФ ВолГУ»).
2. Управление → Сообщения → «Возможность получать сообщения»: **включить**.
   Тип системы управления сообщениями: **Статические адреса**.
3. Там же вкладка «Боты» → включить Long Poll → скопировать **ключ серверных API**.
4. Разрешения токена: `messages`, `photos`, `notify`.
   Доступные события: **«Личные сообщения»** — обязательно включить.
5. Ваш VK ID администратора — это номер профиля (id), НЕ telegram id 1746985964.
   Узнать свой VK ID: vk.com/id… в адресной строке или через getProfilesInfo.

### Шаг 3. Установить зависимости (Git Bash, в папке проекта)

```bash
source venv/Scripts/activate        # ваш существующий venv подходит
cd vk_bot
pip install -r requirements.txt
```

### Шаг 4. Настроить .env

```bash
cp .env.example .env
notepad .env    # или nano .env — вписать VK_TOKEN, VK_GROUP_ID, VK_ADMIN_ID
```

`.env` уже добавлен в `.gitignore` — токен в Git не попадёт. Никогда
не присылайте токен в чат и не вставляйте его в код.

### Шаг 5. Запустить

```bash
python vk_bot.py
```

Напишите боту в ЛС сообщества `/start` — должен появиться выбор курса.
Остановка — Ctrl+C. Бот запускается независимо от Telegram-бота.

## Реализованные функции (аналог TG-бота)

- `/start`, выбор курса → направления → группы, сохранение профиля (SQLite `vk_users`).
- `/today`, `/tomorrow`, `/week`, `/whatstar`, `/profile`, `/settings`, `/help`.
- Кнопки: 📅 Сегодня, 📅 Завтра, 📚 Неделя, ⭐ Какая неделя?, 👤 Мой профиль,
  ⚙️ Настройки, ℹ️ Помощь (+ постоянная клавиатура сообщества).
- Без профиля запрос расписания предлагает настроить профиль.
- Звёздные недели: отсчёт с пн 31.08.2026 (`*`), чередование; занятия с
  конкретными датами показываются только в эти даты; пустые пары скрыты;
  сокращения `л./лаб./пр.` → `Лекция/Лабораторная/Практика`; время ПН–ПТ и СБ разное.
- Замена предыдущего ответа: удаление последнего сообщения бота (в VK оно
  доступно ≤24 часов; старше — просто отправляется новое).
- `/broadcast` — только для `VK_ADMIN_ID`, устойчив к ошибкам отдельных
  получателей, тем, кто запретил ЛС, сообщение просто не доставляется.

## Пройденные проверки (без сети)

- Все даты звёздных недель из ТЗ (31.08–25.10.2026) ✓, даты до начала отсчёта не падают ✓
- Фильтрация `*`/`**`/дат/пустых пар, субботнее время ✓
- Мастер курс→направление→группа, сохранение/смена профиля ✓
- Разбор команд, payload-кнопок, ввода группы текстом ✓
- Рассылка: не-админ отклонён; ошибка одного получателя не рвёт рассылку ✓
